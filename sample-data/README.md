# Synthetic sample data

`hourly.csv` is a deterministic, fictional 24-hour profile created for this repository. It is not measured generation or market data and must not be used as a forecast.

`scenario.json` records the data provenance, units, operating constraints, financial assumptions, and an explicit annualization factor of 365. Annualizing a representative day is suitable only for demonstrating the calculation flow; a real study needs a complete, licensed time series with timezone and gap handling reviewed for its market.

`sensitivity-spec.json` is a matching example spec for `pv-bess sensitivity`: price level plus or minus 20%, battery capacity at half and one-and-a-half times, and degradation cost at 0 and 20 EUR/MWh. The worked result table is in [docs/sensitivity.md](../docs/sensitivity.md).

[`monthly/`](monthly/README.md) holds a larger fixture: a deterministic synthetic 744-hour month generated by `tools/make_synthetic_year.py`, with its own scenario and annualization convention. A full 8,760-hour year from the same generator was benchmarked but is not committed because its solve time is impractical and unreliable on modest hardware; the measurements are published in [docs/benchmarks.md](../docs/benchmarks.md).
